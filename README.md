# YandexMaps Review Integration Demo

### Instruction for dev

1. To quick start run:
```
make start
```

2. To build project:
```
make build
```

3. To run project:
```
make up
```

4. To prepare project for use:
```
make prepare
```

5. To stop services:
```
make down
```

6. To get logs:
```
make logs [service]
```

7. To restart services:
```
make restart [service]
```

8. To execute commands in services:
```
make exec [service] [command]
```
